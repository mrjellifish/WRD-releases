# WRD

A spacious notepad for your DAW, with independent project notes, local crash recovery, a colourful spectrum underlay and the LEV/FAVE/TUN family menu.

## Download

[Download WRD 0.2.0 beta for macOS Apple Silicon](https://github.com/mrjellifish/WRD-releases/releases/tag/v0.2.0-beta.1)

Includes VST3, Audio Unit and standalone. Extract the ZIP, open WRDUpdater.app and choose Install WRD. Save your session and unload WRD first; previous versions are backed up. This beta is ad-hoc signed, not Apple-notarized. See the release notes for macOS approval steps and known limits.

WRD is also available through **Plugins → Check** in compatible family plugins after their next catalogue refresh.

Notes are plain text, saved with the DAW project. Mono defaults, font/colour controls, bullets and indentation keep writing simple. Background transparency requires a compatible floating macOS host window; text stays solid and the spectrum is 50% opaque. No accounts, cloud or shared notebooks.

This repository contains public installers and signed update metadata. Product source is maintained privately. No Intel or Windows package is offered.
